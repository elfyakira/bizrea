## 1-1. マーケティング戦略（専門家①の視点）

### コンバージョンファネル設計

#### ターゲット①: 中小企業の経営者（30〜55歳、東海エリア、採用・営業に課題あり）

```
認知 → 興味 → 比較検討 → 行動 → コンバージョン
  ↓      ↓         ↓        ↓          ↓
SEO    事例閲覧  メリット   オファー    フォーム
SNS    動画視聴  料金確認   無料相談    送信完了
紹介   記事熟読  FAQ確認
```

**認知段階**:
- 流入経路: Google検索「採用 ブランディング」「企業ブランディング 方法」「会社紹介 動画」、SNS（経営者コミュニティ）、既存クライアントからの紹介
- 最初に見るページ: トップページ（60%）、導入事例の個別企業ページ（25%）、コンテンツ紹介ページ（15%）
- この段階での訴求: 「採用も営業も変わる。社長の言葉を"成果が出る形"にする」
- 離脱防止策: ファーストビュー3秒で「社長インタビュー × 動画 × 雑誌 × WEB で企業の本質を届ける」を視覚的に伝える。導入企業のロゴ帯を直下に配置。

**興味段階**:
- 見るページ: 導入事例（企業一覧）、BIZREAとは、導入メリット
- 滞在時間目標: 各ページ2分30秒以上
- この段階での訴求: 「制作して終わりではない。営業・採用・定着、すべてに使える"企業ツール"になる」
- 次のアクションへの誘導: 「導入企業の声を見る」で事例ページへ、「3分でわかるBIZREA」で動画視聴へ

**比較検討段階**:
- 見るページ: 料金・プラン、制作の流れ、よくある質問
- 競合と比較される要素: (1)制作物の活用範囲の広さ (2)コンテンツの具体性・質 (3)費用対効果
- この段階での訴求: 「採用動画だけ、パンフレットだけ、HPだけ——ではなく、すべてが連動するから成果が出る」
- 不安解消コンテンツ: 導入企業の具体的な成果エピソード、制作フロー（社長が話すだけでOK）、FAQ「社長が話すのが苦手でも大丈夫？」

**行動段階**:
- 最後のハードル: 「本当に費用に見合う効果が出るのか」「ただの制作会社と何が違うのか」
- 背中を押す要素: 「無料相談で御社に最適な活用プランをご提案」「掲載企業数○社突破」「導入企業の応募率が平均2.4倍に」
- CTAの配置: (1)共感セクション直後 (2)実績セクション直後 (3)ページ末尾 + SPフローティング

**コンバージョン**:
- 目標行動: 無料相談フォーム送信 / 電話問い合わせ
- フォーム到達率目標: 8%
- フォーム完了率目標: 65%
- 離脱防止策: 項目数5個（会社名、担当者名、電話番号、メールアドレス、相談内容の選択式）、入力時間2分以内

- ストーリーテリング: 「なぜBIZREAが生まれたのか」→ 配置: コンセプトセクション冒頭

### ABテスト推奨項目

**1. トップページのメインキャッチコピー**:
- パターンA: 「いい会社が、埋もれる時代を終わらせる。」（ビジョン訴求）
- パターンB: 「社長の言葉が、営業と採用を変える。」（具体的ベネフィット）
- 勝利予測: パターンB（理由: ターゲットの経営者は具体的な成果を求めている。ただしブランド構築期はAが有効な可能性も）

**2. CTAボタンの文言**:
- パターンA: 「無料で相談してみる」
- パターンB: 「まずは話を聞いてみる」
- パターンC: 「3分で分かる資料をもらう」
- 勝利予測: パターンB（理由: 「相談」より「話を聞く」のほうがハードルが低い。Cは資料請求という明確なアクションで迷いが少ない）

**3. ファーストビューの背景**:
- パターンA: 社長インタビューの撮影風景（動画背景）
- パターンB: 完成した雑誌・動画・WEBの制作物を並べたスタティック画像
- 勝利予測: パターンA（理由: 動きがあるほうが注目を集め、サービスの臨場感が伝わる）

**4. 共感セクションの悩み数**:
- パターンA: 3つ（シンプル）
- パターンB: 5つ（網羅的）
- 勝利予測: パターンA（理由: 多すぎると読み飛ばされる。3つに絞って各項目の共感深度を上げる）

**5. 実績セクションの構成**:
- パターンA: 数字（掲載企業数・制作実績数）を大きく表示
- パターンB: 導入企業の成果エピソード（ストーリー型）
- 勝利予測: パターンA（理由: ファーストインプレッションでは数字のインパクトが強い。ただしBは滞在時間と信頼度で勝る可能性）

**6. オファーの内容**:
- パターンA: 「無料相談」
- パターンB: 「無料で"御社の伝え方"診断」
- 勝利予測: パターンB（理由: 具体的な価値が明示されているため、行動の理由が明確になる）

**7. フローティングCTAの表示タイミング（SP）**:
- パターンA: スクロール開始後すぐに表示
- パターンB: 共感セクション到達後に表示（ページの20%スクロール後）
- 勝利予測: パターンB（理由: 早すぎる表示は邪魔に感じる。悩みに共感した後のほうが行動意欲が高い）

## 1-2. 採用ブランディング戦略（専門家②の視点）

※BIZREAは「自社の採用」ではなく「クライアント企業の採用支援」が目的。
この戦略は、BIZREAの個別企業ページ（掲載企業ページ）が求職者にどう機能するかを設計する。

### 求職者インサイト分析

BIZREAに掲載される企業の求職者（主に東海エリアの20〜40代）が本当に知りたいこと:

**若手求職者（20代、第二新卒・キャリアチェンジ）の場合**:
1. 最重要: この会社は「見かけ倒し」じゃないか？（リアルな姿を知りたい）
2. 重要: 社長はどんな人か？（ワンマンじゃないか、現場を理解しているか）
3. 重要: 自分と似た境遇の人がいるか？（未経験入社、異業種転職）
4. やや重要: 具体的にどんな仕事をするのか？（1日の流れ）
5. やや重要: 給与・休日・福利厚生のリアルな数字

**対応策（個別企業ページでの表現）**:
- 「リアル」→ 社長インタビューで具体的なエピソードを語らせる。抽象的な理念語りは排除
- 「社長の人柄」→ 動画で表情・声のトーン・話し方を伝える。テキストでは伝わらない温度感
- 「似た境遇の人」→ 記事内で社員の入社経緯を紹介。「前職は○○だったけど——」というリアルな転職ストーリー
- 「仕事内容」→ 抽象的な「やりがい」ではなく、具体的な業務と成長実感を言語化
- 「待遇」→ 企業ページ内に採用情報へのリンクを明示。BIZREAページでは「雰囲気」を、企業HPでは「条件」を伝える役割分担

**中堅求職者（30〜40代、経験者・管理職候補）の場合**:
1. 最重要: この会社に将来性はあるか？（経営の方向性）
2. 重要: 自分の経験が活かせるか？（求められる人材像）
3. 重要: 社長のビジョンに共感できるか？
4. やや重要: 社風・意思決定のスピード感
5. やや重要: 年収レンジ・ポジション

**対応策**:
- 「将来性」→ 社長インタビューで事業の方向性・投資計画を語らせる
- 「経験の活用」→ 「こういう人に来てほしい」を社長の言葉で具体的に
- 「ビジョン共感」→ 動画の力で社長の熱量と本気度を伝える
- 「社風」→ 記事内で意思決定や社内コミュニケーションの具体例を入れる

### 応募ハードルを下げる情報開示戦略（個別企業ページの設計原則）

- **ステップ1: ページ訪問時（ハードル: 低）**
  - 開示情報: 社長のビジョン、会社の雰囲気、事業の方向性
  - 目標: 「この会社、もっと知りたい」と思わせる
  - 具体策: インパクトのある見出し + 社長の写真 + 動画サムネイル

- **ステップ2: 記事を読み進めた時（ハードル: 中）**
  - 開示情報: 社長の人柄、社員の声、仕事の具体的な内容、会社の課題と向き合い方
  - 目標: 「この社長、この会社、信頼できる」と思わせる
  - 具体策: 具体的なエピソード中心。美化せず、課題にも触れる正直さが信頼を生む

- **ステップ3: 動画を視聴した時（ハードル: やや低下）**
  - 開示情報: 社長の表情・声のトーン、職場の雰囲気、社員の表情
  - 目標: 「ここで働く自分がイメージできる」
  - 具体策: テキストでは伝わらない"温度感"を動画で届ける

- **ステップ4: 企業HPへ遷移（ハードル: 高→低に転換）**
  - 誘導要素: 「この企業の採用情報を見る」ボタン
  - 目標: 記事と動画で十分に理解・共感したうえで、条件確認→応募へ
  - 具体策: BIZREAで「感情」を動かし、企業HPで「条件」を確認する導線設計

### 「入りたい」と思わせる感情設計（個別企業ページ用）

**社長インタビュー記事**:
- 目標感情: 「この社長の下で働きたい」「この会社には本物の想いがある」
- 文言の工夫:
  - NG例: 「当社は人材を大切にしています」（どの会社も言う）
  - OK例: 「うちの社員が辞めたいと言ってきた時、僕は必ず2時間話を聞く。それで辞めるなら仕方ない。でも、話を聞いたら解決することのほうが多いんです」（社長の具体的な行動）
- 写真の工夫:
  - NG例: 社長室でスーツを着たポートレート
  - OK例: 現場で社員と話している、工場を歩いている、会議で身振り手振りしている

**動画コンテンツ**:
- 目標感情: 「文字だけでは伝わらなかった人柄が見えた」
- 構成の工夫:
  - 冒頭15秒: 社長の最も印象的な一言（フック）
  - 本編: インタビューの自然な流れ（台本読みNG、対話形式）
  - 締め: 求職者・取引先へのメッセージ（カメラ目線で直接語りかけ）

## 1-3. ブランド体験設計（専門家③の視点）

### ブランドの「人格」定義

**もしBIZREAが人だったら...**
- 年齢: 35歳（若すぎず、でも現場感がある。時代の空気を読める世代）
- 性格: 本質を見抜く目を持つ。飾らない。相手の話をよく聞く。でも芯がある。
- 話し方: 丁寧だけどフランク。業界用語は使わず、相手が分かる言葉で話す。「つまり、こういうことですよね」と本質を一言でまとめるのが上手い。
- 服装: ジャケット + シンプルなインナー。ネクタイはしない。清潔感はあるが、かっちりしすぎない。
- 印象: 「この人に任せれば、うちの会社の良さをちゃんと伝えてくれる」

**この人格をデザインに落とし込む**:
- 色: ダークネイビー（#1B2D4F）= 誠実さ、信頼、本質を見る深さ。テラコッタ（#C45A3C）= 温もり、情熱、人間味。
- フォント: Noto Sans JP（本文）、Noto Serif JP（見出しのアクセントに部分使用）。ゴシック体ベースで現代的かつ読みやすく。セリフ体は「ここぞ」の見出しだけに使い、格と温かみを添える。
- 写真: 作り込んだスタジオ撮影ではなく、実際のインタビュー現場、取材風景、社長の自然な表情。光は自然光を意識。
- 余白: 十分に取る。詰め込まない。情報が「呼吸している」感覚。品がある。
- 動き: ほとんど静的。本当に見てほしいもの（メインキャッチ、CTA、実績数字）だけ、控えめに動く。

### ビジュアル階層設計

**トップページのファーストビュー（視線の流れ）**:
```
1. 背景映像（社長インタビューの撮影風景）← 最初に空気感を感じる
   ↓
2. メインキャッチコピー（Noto Serif JP / 48px / #FFFFFF）
   「社長の言葉が、営業と採用を変える。」
   ↓
3. サブコピー（Noto Sans JP / 18px / rgba(255,255,255,0.85)）
   「社長インタビューを軸にした動画・雑誌・WEBで、
    企業の"本質"を"伝わる形"にする。」
   ↓
4. CTAボタン（テラコッタ / #C45A3C / 白文字）
   「まずは話を聞いてみる」
```

PC版レイアウト: キャッチコピーは左寄せ。右側に余白を残し、背景映像の空気感を活かす。テキスト背景に薄いグラデーション（左から右へ、rgba(0,0,0,0.5)→透明）を敷き、可読性を確保。中央揃えにはしない。

SP版レイアウト: テキスト中央寄せ。背景全体にオーバーレイ（rgba(27,45,79,0.55)）。フォントサイズは28px / 14px。

### 色彩心理とブランド体験

**メインカラー: ダークネイビー #1B2D4F**
- 心理効果: 信頼、誠実、深み、知性
- 使用箇所: ヘッダーテキスト、見出しテキスト、フッター背景、ページヒーロー背景、最終CTAセクション背景
- 使用比率: サイト全体の色面積の約15%
- 避けるべき使い方: 大きな面積でベタ塗りしすぎない（重くなる）。CTAボタンには使わない（目立たない）

**アクセントカラー: テラコッタ #C45A3C**
- 心理効果: 温もり、情熱、行動力、人間味
- 使用箇所: CTAボタン、重要なリンクテキスト、オファーセクション背景、ホバーエフェクトの一部
- 使用比率: サイト全体の色面積の約5%（少ないからこそ目立つ）
- 注意: テキストに使う場合はコントラスト比を確認。白背景上では16px以上に限定。

**サブカラー: ウォームグレー #F6F4F1**
- 心理効果: 温かみ、落ち着き、上品さ（純白より柔らかい印象）
- 使用箇所: 交互セクションの背景、カード背景（使う場合）
- 注意: 白（#FFFFFF）との使い分けが重要。白は「主役コンテンツの背景」、ウォームグレーは「補足・一覧の背景」

**テキストカラー: ダークチャコール #222222**
- 使用箇所: 本文テキスト、見出しテキスト（メインカラーを使わない場合）
- 注意: 純黒（#000000）は使わない。硬すぎる印象になる。

**テキストカラー（淡）: #5A5A5A**
- 使用箇所: キャプション、補足テキスト、フォームのプレースホルダー、日付表示

### 余白とリズムの設計

**余白の基準値**:
- セクション間の余白: PC 120px / SP 72px（大きく呼吸させる）
- 見出しとリード文の余白: PC 20px / SP 14px（近い = 関連が強い）
- リード文と本コンテンツの余白: PC 48px / SP 32px（少し離す = 役割が違う）
- 段落間の余白: PC 28px / SP 20px
- リスト項目間の余白: PC 16px / SP 12px

**重要な原則**: 余白は「意味」で決める。関連する要素は近づけ、関連しない要素は離す。8の倍数に固執しない。

**ページ全体のリズム設計（TOPページ例）**:
```
全幅映像（FV） ← インパクト、没入感
  ↓ 120px
テキスト中心（共感セクション） ← 落ち着いて読む、白背景

中間CTA① ← 控えめな背景色で自然に
  ↓ 120px
非対称レイアウト（解決策） ← 画像とテキストが交互、リズム感
  ↓ 120px

  ↓ 0px

  ↓ 120px
構造的レイアウト（サービス詳細） ← 整理された情報
  ↓ 120px

  ↓ 120px

  ↓ 120px

```

### 反AIデザインの具体的実装ルール

**カード使用ルール**:
- 導入事例の企業一覧: カード使用OK（本来のカードUIの意味がある場面）
- ただしborderは使わない。背景色の差（白 on ウォームグレー）とサムネイル画像で区別
- box-shadowは hover時のみ、ごく控えめに（0 4px 20px rgba(0,0,0,0.06)）
- 角丸は4px（AIの典型的な12pxを避ける）

**ボーダー使用ルール**:
- テーブル: 使用OK（視認性のため）
- セクション区切り: 使用NG（余白で区切る）
- カード: 使用NG（背景色で区別）
- フォーム入力欄: 下線のみ（ボックスではなく下線スタイル）

**影の使用ルール**:
- 通常時: 原則なし
- ホバー時: 控えめな影（カードのみ、0 4px 20px rgba(0,0,0,0.06)）
- ヘッダー（スクロール後）: 0 1px 0 rgba(0,0,0,0.06)（ほぼ見えないライン）

**アニメーション使用ルール**:
- 使用する場面: ファーストビューのテキスト出現（1回のみ）、実績数字のカウントアップ（スクロールで1回）、SPフローティングCTAの出現
- 使用しない場面: セクションのフェードイン、カードのスライドイン、画像の拡大、ボタンのscale変化
- 時間: 0.4s〜0.8s（0.3sと0.6sのAI典型値を避ける）
- イージング: cubic-bezier(0.22, 1, 0.36, 1)（自然な減速感）

**レイアウトのバリエーション（TOPページ内の変化）**:
- FV: 全幅画像 + 左寄せテキスト
- 共感: 中央寄せテキスト、最大幅680px
- 解決策: 左画像+右テキスト → 右画像+左テキスト → 全幅（交互配置）
- 実績: 数字は横並び、お客様の声は2カラム非対称（大+小）
- サービス: 全幅画像セパレーター + テキストブロック
- FAQ: 1カラム中央、最大幅780px

**ホバーエフェクトの多様性**:
- CTAボタン: 背景色が少し濃くなる（#C45A3C → #A34830）+ translateY(-1px)
- テキストリンク: 下線がアニメーションで現れる（左から右へ）
- カード（事例一覧）: サムネイル画像がごく僅かに拡大（scale 1.02、overflow hidden）
- ナビリンク: テキスト色がアクセントカラーに変わる（transition 0.2s）
