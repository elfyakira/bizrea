# 導入事例（企業一覧） ページ詳細設計

> 企業名: Bizrea
> 作成日: 2026-04-01
> ファイル: 05_cases.md

---

## ページ概要

- **目的**: 掲載企業の一覧を見せ、BIZREAの実績の厚みと多様性を伝える。「自分の業種でも使えそう」と思わせる。同時に求職者の企業探索のハブとして機能。
- **ターゲット**: 経営者（「同業種の事例があるか」確認）、求職者（「興味ある企業を見つけたい」）
- **CV導線上の役割**: 興味→比較検討段階。このページ自体がSEO流入ページとしても重要。
- **滞在時間目標**: 2分（一覧を見て個別ページに遷移するまで）
- **次のアクション**: 個別企業ページへの遷移

### レイアウト
- 構成: 1カラム、最大幅1120px、中央寄せ
- 背景: #FFFFFF
- 余白: 上56px 下40px（PC）/ 上36px 下24px（SP）

### コンテンツ

**フィルターUI**:

業種タグ（横並び、折り返しあり）:
- 「すべて」「製造業」「建設業」「物流業」「IT・通信」「サービス業」「その他」

- 角丸: 20px（ピル型。タグはボタンではなくフィルターなので、ピル型が自然）

- 業種タグとの余白: 12px

## セクション③: 企業一覧グリッド

**設計意図**: 多くの企業を効率的に一覧させつつ、各企業の「顔」が見えるように。ここはカードUIの正当な使用場面。

### レイアウト
- 構成: グリッド PC 3列 / SP 1列
- 背景: #F6F4F1
- 余白: 上0 下80px（PC）/ 上0 下48px（SP）
- グリッド間隔: PC 28px / SP 20px
- コンテナ最大幅: 1120px、中央寄せ
- コンテナ左右余白: PC 40px / SP 20px

### 企業カードの設計

**カードスタイル**:
- 背景: #FFFFFF
- ボーダー: なし
- 影: なし（通常時）
- ホバー: box-shadow 0 4px 20px rgba(0,0,0,0.06)、サムネイルが scale(1.02)
- 角丸: 4px
- overflow: hidden

**カード構成（上から）**:

サムネイル画像:
- 内容: 社長のインタビュー中のベストショット or 企業の代表的な写真
- アスペクト比: 3:2
- object-fit: cover
- ホバー時: scale(1.02)、transition 0.4s ease-out、overflow hidden

テキストエリア（サムネイル直下）:
- パディング: 24px 20px

業種タグ:
- テキスト: 「製造業」等
- Noto Sans JP Medium / 12px / #C45A3C
- 背景なし（テキストのみ）

企業名:
- テキスト: 「株式会社○○」
- Noto Sans JP Bold / 18px / #222222
- タグとの余白: 8px

代表者名:
- テキスト: 「代表取締役 ○○ ○○」
- Noto Sans JP Regular / 13px / #5A5A5A
- 企業名との余白: 4px

キャッチ（一言）:
- テキスト: 「"ものづくりの現場から、未来をつくる"」等（社長の一言）
- Noto Sans JP Regular / 14px / #222222 / 行間1.6
- 代表者名との余白: 12px
- 2行まで、超過時は省略（...）

所在地:
- テキスト: 「愛知県名古屋市」
- Noto Sans JP Regular / 12px / #5A5A5A
- キャッチとの余白: 12px

カード全体がクリッカブル（リンク先: /cases/[企業スラッグ]）

### ページネーション
- 企業数が多い場合: 12件/ページ表示
- 「もっと見る」ボタン（追加読み込み）or ページネーション
- ボタン: 「さらに表示する」/ Noto Sans JP Medium / 15px / #1B2D4F / ボーダー 1px solid #1B2D4F / 背景透明 / パディング 14px 40px / 角丸 4px
- ホバー: 背景#1B2D4F、テキスト#FFFFFF
- 中央寄せ、グリッドとの余白: PC 48px / SP 32px
