## セクション⑤: 連動の仕組み

**設計意図**: 3つが連動することで生まれる相乗効果を視覚的に理解させる。

### レイアウト
- 構成: 見出し + フロー図 + 活用シーン例
- 背景: #F6F4F1
- 余白: 上100px 下100px（PC）/ 上56px 下56px（SP）
- 最大幅: 960px、中央寄せ

### コンテンツ

**見出し**:
「紙 → 動画 → WEB、すべてが繋がる」
- Noto Sans JP Bold / PC 28px / SP 22px / #222222
- 中央寄せ
- 見出し下余白: PC 48px / SP 32px

**フロー図**:
横並び3ステップ（PC）/ 縦積み（SP）

ステップ1:
「雑誌を手渡す」→「QRコードで動画に誘導」
- 小アイコン（雑誌のラインイラスト）+ テキスト
- 矢印（→）でステップ2に接続

ステップ2:
「動画を視聴」→「リンクでWEBページへ」
- 小アイコン（再生ボタンのラインイラスト）+ テキスト
- 矢印でステップ3に接続

ステップ3:
「WEBで詳しく読む」→「問い合わせ / 応募」
- 小アイコン（PCモニターのラインイラスト）+ テキスト

- 各ステップ: テキストはNoto Sans JP Medium / 15px / #222222
- 矢印: #E0DDD8、太さ2px
- アイコン: ラインイラスト、#1B2D4F、24px × 24px
- SP: 縦積み、矢印は下向き（↓）

**活用シーン例**:
フロー図との余白: PC 56px / SP 36px

見出し: 「活用シーン」
- Noto Sans JP Bold / PC 20px / SP 18px / #222222

シーン一覧（テキストリスト、装飾なし）:

「営業: 商談前に雑誌を郵送 → 相手がQRで動画視聴 → WEBで事業理解 → 商談がスムーズに」

「採用: 面接前にWEBページのURLを送付 → 動画で社長の人柄を確認 → "共感"した状態で面接へ」

「定着: 入社初日に雑誌を配布 → 動画で会社の歴史・ビジョンを共有 → WEBページをいつでも振り返り」

- 各シーンのラベル（営業/採用/定着）: Noto Sans JP Bold / 15px / #C45A3C
- 説明テキスト: Noto Sans JP Regular / 15px / #222222 / 行間1.7
- シーン間余白: PC 20px / SP 16px
- emダッシュや記号での装飾なし。ラベルの色で区別。
