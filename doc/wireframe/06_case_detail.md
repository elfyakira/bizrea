## ページ概要

- **目的**: 掲載企業の「本質」を伝える。社長インタビュー記事 + 動画で、読者の信頼と共感を獲得する。BIZREAの「SEO資産」の本体。
- **ターゲット**: 求職者（この企業のリアルを知りたい）、取引先候補（この企業と取引できるか確認したい）、掲載を検討中の企業（BIZREAで何ができるか参考にしたい）
- **CV導線上の役割**: 求職者→企業HPの採用ページへ遷移。掲載検討企業→BIZREAへの問い合わせ。
- **滞在時間目標**: 5分以上（記事読了 + 動画視聴）
- **次のアクション**: 企業HPへの遷移（求職者）/ BIZREAへの問い合わせ（掲載検討企業）

※このページはテンプレートです。掲載企業ごとにコンテンツが差し替わります。

## セクション③: 社長インタビュー記事本文

**設計意図**: BIZREAのコアコンテンツ。社長の言葉をそのまま届ける。読みやすさと"リアル感"を両立。

### レイアウト
- 構成: 1カラム中央寄せ、最大幅720px
- 背景: #FFFFFF
- 余白: 上0 下80px（PC）/ 上0 下48px（SP）

### コンテンツ構成（テンプレート）

記事は以下の構成を基本とする。各企業のインタビュー内容により調整。

**章立て（3〜5章）**:

章見出し例:
「創業の原点——"誰のために働くのか"を問い続けた日々」
- Noto Sans JP Bold / PC 24px / SP 20px / #222222
- 前章との余白: PC 64px / SP 40px
- 見出し下余白: PC 24px / SP 18px

本文例:
「——創業のきっかけを教えてください。

○○氏: もともと大手メーカーで10年ほど働いていたんです。技術力には自信がありました。でもある時、自分がつくっているものが誰の役に立っているのか、まったく見えなくなった。組織が大きすぎて、お客さんの顔が見えない。

それで、32歳の時に独立しました。最初は自宅の一室から。妻には相当心配されましたね（笑）。

——最初は苦労されたのでしょうか。

○○氏: もちろん。最初の1年は売上ゼロの月もありました。でも、ひとつだけ決めていたことがあるんです。"目の前のお客さんが本当に困っていることを、本気で解決する"。それだけはブレなかった。」

- 本文: Noto Sans JP Regular / PC 16px / SP 15px / #222222 / 行間2.0
- インタビュアーの質問: Noto Sans JP Bold / PC 16px / SP 15px / #1B2D4F
- 質問と回答の余白: 16px
- 段落間余白: 24px

**記事中の写真**:
章と章の間に挿入。テキスト幅を超えて少し広めに（最大幅840px）。

写真指示（企業ごとに異なる）:
- 社長が現場で働いている / 社員と話している / 製品を手に取っている
- 自然光、キャンディッドフォト（ポーズ写真NG）
- アスペクト比: 3:2 or 16:9（写真によりバリエーション）
- 角丸: なし
- キャプション: Noto Sans JP Regular / 13px / #5A5A5A / 写真下8px
- 写真と前後テキストの余白: PC 48px / SP 32px

**引用ブロック（社長の印象的な一言）**:
記事の要所に配置（1記事あたり1〜2箇所）

「"うちの社員が辞めたいと言ってきた時、僕は必ず2時間話を聞く。
それで辞めるなら仕方ない。
でも、話を聞いたら解決することのほうが多いんです。"」

- Noto Serif JP Regular / PC 22px / SP 18px / #1B2D4F
- 行間: 1.7
- 左ボーダー: 3px solid #C45A3C
- 左パディング: 24px
- 上下余白: PC 48px / SP 32px
- 背景: なし
